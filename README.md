## ✨ Features

- 🛍️ **Products Module** — collapsible sub-menu, Firestore-backed Add Product form, pill-style sub-navigation
- 🔐 **Secure Auth** — login system built on Firebase Authentication
- 🌐 **Public Landing Page** — feature cards, JSON-LD schema markup for SEO ✅, custom favicon 🎯
- 📜 **Privacy Policy Page** — fully compliant and linked
- 🎨 **Custom Theming** — consistent FRALEN navy 🟦 + amber 🟨 design system
- ⚡ **Fast & Lightweight** — no heavy frameworks, pure HTML/CSS/JS
